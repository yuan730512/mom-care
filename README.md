# 陪伴媽媽 — 三兄弟陪伴點數網站

三兄弟各自用 Gmail 登入，在日曆上登錄陪伴媽媽的紀錄並附照片，系統依點數表計點，
可看月／季／年統計與基金分配試算，並有討論區投票。

## 檔案說明

| 路徑 | 用途 |
| --- | --- |
| `docs/index.html` `style.css` `app.js` | 網站畫面與操作 |
| `docs/logic.js` | 點數、期間、分配的計算（純函式） |
| `docs/store-firebase.js` | 正式模式：Google 登入、Firestore（紀錄與照片都存這裡） |
| `docs/store-demo.js` | 示範模式：假資料（網址加 `?demo=1`，或尚未填 config 時自動啟用） |
| `docs/firebase-config.js` | **要填入你的 Firebase 設定** |
| `firestore.rules` | 安全規則（誰能讀寫什麼） |
| `firebase.json` `firestore.indexes.json` | Firebase 專案設定 |
| `SETUP.md` | 部署步驟 |

## 規則（寫在程式與安全規則裡）

1. 只有「家人名單」內的 Gmail 能登入；名單由管理者維護。
2. 紀錄只能登錄自己的，日期限今天往前 N 天內（預設 7 天，可在設定調整）。
3. 登錄後 N 天為異議期（預設 7 天）：本人可修改或作廢，他人可提出異議；每次修改留下歷史，任何人都不能刪除紀錄。
4. 異議期過後紀錄固定；有未撤回的異議則不列入計算。
5. 點數在登錄當下就固定（存進紀錄），之後改點數表不影響舊紀錄。
6. 點數表每次修改產生新版本並留存；提案投票過半、管理者結案時可自動套用。
7. 統計依「有效紀錄」計算，分配金額＝基金 × 各人點數 ÷ 總點數，餘數歸最後一人。
